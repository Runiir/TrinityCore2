# WCL reference library (Cataclysm Classic 4.4.2)

Real-player DPS references per raid, boss and mode, for bots wearing that raid's content-phase gear. Built by GPT-6.1 Sol driving one Chrome tab per unit on classic.warcraftlogs.com (route and rules in each archive's `PROGRESS.md`). Gear match first, then parse: competent players, not top 1%. Reports older than about two years are archived by WCL and unreadable.

Each raid is one DVC-tracked archive with its per-unit library JSON, the raw Sol captures (prompt, log, final summary, JSON) and the build scripts. Fetch with `pixi run dvc pull artifacts/wcl_reference_library/<raid>_<date>.tar.gz.dvc`.

| Archive | Contents |

| `bastion_of_twilight_20261001.tar.gz` | The Bastion of Twilight, all bosses and modes incl. Sinestra heroic (18 units) |

Still being collected (archived when each raid completes): Throne of the Four Winds, Baradin Hold, Firelands, Dragon Soul. Specs with fewer than 3 kills in band are listed per unit in the archive's `PROGRESS.md` (Gaps) for a later gap-fill.
