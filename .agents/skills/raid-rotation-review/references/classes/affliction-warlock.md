# Affliction warlock review card

- Resolve the current promoted WoWSims request, result, revision, DPS, and action cadence from the reference catalog for every review. Do not preserve a prior run's reference identity as evergreen guidance.
- Treat a promoted stationary self-provided result as a comparison condition, not a live-raid target without effective-stat and condition parity.
- Verify the current APL condition before recommending Fel Flame 77799; do not loosen an aura or movement gate from live aggregate counts alone.
- Live `spell_cast` is submission evidence. Repeated `cast_combat_spell` with result `Casting` identifies scheduling occupancy, not a second submission or a landed spell.
- A `Casting` executor result with `gates.casting=false` can be the cast-time movement-stop yield. Bind current generic/channeled spell identity, native movement state, vehicle state, and active task ownership before assigning the loss to a class action.
- `moving_fraction` in combat aggregates is event-weighted; never use it as wall-clock movement time.
- Compare landed ticks/hits, dot uptime, pet uptime, target identity, and elapsed conditions. Do not tune coefficients from total DPS alone.
